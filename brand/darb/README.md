# Darb brand (درب)

New product name and look, supplied by the owner (Figma export, 1 Nov 2026).

- Arabic name: درب. Latin name: Darb.
- `logo.png` (550x228) is the wordmark with the road and pin. `logo-small.png` is the 210x87 original.
- `screens/*.svg` are the design references (390x844): login, new trip, available rides, confirm booking. The `.png` files next to them are renders for quick viewing.
- Palette read from the SVGs: primary orange `#FA5F12`, ink `#1C1A1A`, text grey `#707070`, hint grey `#AEAEAE`, card fill `#F6F6F6`/`#F8F8F8`, price green `#3A7C07`, route-origin green `#5A6B3A`, route-destination red `#EB3223`, white page.
- Only the visible brand is renamed. Technical identifiers (Android/iOS bundle id `ps.darb.mobile`, npm scope `@darb`, database name, domain `darb.aynur.ps`, env var names) stay until the owner decides on them separately.
- In Arabic text the word "مسار" also means "route"; only the brand ("مساري") is renamed, never "route" wording.
